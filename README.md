# Система динамического измерения габаритов грузов на конвейере (Ozon Case)

Программно-аппаратный комплекс для высокоточного измерения габаритов ($L, W, H$) произвольных отправлений, перемещающихся по конвейерной ленте со скоростью $1{,}0\text{ м/с}$.

Решение разработано в рамках отборочного кейса в Мастерскую Ozon (Трек: Компьютерное зрение).

##  Ключевые характеристики системы

* **Скорость конвейера:** $1{,}0\text{ м/с}$ ($1000\text{ мм/с}$)
* **Диапазон габаритов:** от $10 \times 10 \times 10\text{ мм}$ до $400 \times 300 \times 300\text{ мм}$
* **Критерий допуска ТЗ:** $\delta_{\max} = \pm \max(0{,}05 \cdot X, 5\text{ мм})$
* **Аппаратный стек:** 
  * 3D-триангуляционный профилометр LMI Gocator 2490 (шаг $\Delta X \approx 0{,}48\text{ мм}$)
  * Инкрементальный энкодер Autonics E40S6-2500 (шаг $\Delta Y = 0{,}5\text{ мм}$)
  * Оптический фотобарьер Omron E3Z-D62 (смещение $150\text{ мм}$)
* **Вычислитель:** Встраиваемый промышленный ПК Advantech ARK-3532 (Edge-вычисления)
* **Задержка обработки (Latency):** $\approx 40\text{-}60\text{ мс}$ (при лимите ТЗ $\le 200\text{ мс}$)


## Архитектура: Гибридный двухконтурный пайплайн

В метрологических системах использование End-to-End регрессии габаритов через нейросети нежелательно из-за эффекта «черного ящика» и отсутствия математических гарантий сходимости. В данном решении реализована **двухконтурная архитектура**:

1. **Основной метрологический контур (Детерминированная геометрия, 95% потока):**
   * Предобработка: вычитание опорной плоскости ленты + медианная фильтрация $3 \times 3$.
   * Сегментация: бинаризация по порогу высоты над лентой ($Z_{\text{порог}} = 3{,}0\text{ мм}$) и морфологическая фильтрация.
   * Высота ($H$): робастный $99{,}5$-й процентиль распределения $Z$ (отсечение задиров скотча и бликов).
   * Длина ($L$) и Ширина ($W$): проекция на $XY \to$ выпуклая оболочка (Convex Hull, Monotone Chain) $\to$ минимальный OBB через вращающиеся калиперы (Rotating Calipers, `cv2.minAreaRect`).
   * Скорость работы: $\approx 40\text{--}60\text{ мс}$.

2. **Вспомогательный ML-контур (Instance Segmentation, разрешение Edge Cases):**
   * Подключается автоматически при фиксации пограничных ситуаций (например, **Double Pick** — слипшиеся коробки без физического зазора или деформированные пакеты).
   * Обычная пороговая бинаризация в таких случаях объединяет объекты в одно пятно, искажая габарит. Модуль инстанс-сегментации (`ml_segmentation.py`) анализирует градиенты нормалей межобъектных стыков и тензор глубины, разделяя склеенный силуэт на независимые маски посылок.
   * Для каждой выделенной маски параллельно вызывается базовый OBB-расчет, что позволяет корректно измерить оба отправления.
